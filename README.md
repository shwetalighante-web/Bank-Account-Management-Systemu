# Bank Account Management System

## Task 01 - Java Internship

A simple Java-based Bank Account Management System developed as part of my Java internship.

## Features

- Create a bank account
- Deposit money
- Withdraw money
- Check account balance
- Display account details
- Validate insufficient balance
- Exit the application

## Technologies Used

- Java
- Scanner
- Classes and Objects
- Constructor
- Methods
- Encapsulation
- Switch Case
- While Loop
- If-Else
